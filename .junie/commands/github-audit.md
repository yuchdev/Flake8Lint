Produce a compact audit note for this GitHub-related activity:

`$ARGUMENTS`

Include:

- the GitHub action taken,
- the repository artifact affected (issue, PR, branch, review, workflow, or release),
- any follow-up required,
- and confirmation that no secrets or private tokens were exposed.

Keep the note concise and suitable for pasting into a status update or PR comment.
